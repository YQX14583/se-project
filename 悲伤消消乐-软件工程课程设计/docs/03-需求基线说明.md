## 1. 基线声明

本次架构设计与系统设计**沿用任务一需求分析文档作为唯一需求基线**。任务二没有新增、删除、合并、拆分或修改功能需求、非功能需求、范围边界和验收指标；因此任务一的需求编号原样保留，并作为设计、实现和测试追溯的主键。

为避免歧义，任务一 FR-SD-01 的“用于排行榜排序”是面向后续联网排行榜（FR-LB-02、03）的规则约束；第一期仍严格执行 FR-LB-01——不实现本地排行榜。第一期的共鸣值仅用于个人历史最佳比较和分享展示。这是既有需求之间的范围解释，不构成需求变更。

## 3. 用户、场景与术语基线

| 编号 | 用户/场景 | 设计必须满足的约束 |
| --- | --- | --- |
| UG-P1 | 减压通勤族 | 单局≤6 分钟、竖屏单手、可中断恢复、失败不挫败 |
| UG-P2 | 情绪自我调节者 | 悲伤值处理过程可见；有非竞争性的表达出口 |
| UG-P3 | 进度收集控 | 真实难度、三星、个人历史最好成绩对比 |
| UG-P4 | 亲子/儿童（低优先） | 内容安全，不单设系统 |
| SC-01 | 通勤碎片游玩 | 信号差/中断时不丢失进度 |
| SC-02 | 情绪低落时自我调节 | 结束时展示处理的悲伤值 |
| SC-03 | 睡前放松 | 低刺激、无强制中断、可自然停止 |
| SC-04 | 桌面端连续刷关 | 横屏可用，支持个人历史成绩对比 |
| SC-05 | 分享情绪结果 | 一键生成可保存或复制的本地分享物 |

| 术语 | 基线定义 |
| --- | --- |
| 悲伤值 `S` | 关卡内情绪负荷数值；`S≤0` 即通关 |
| 疗愈进度 | `1 - S/S₀` 的可视化反向读数，不另存独立数值 |
| 阴云 | 关卡内不可交换障碍；被相邻消除命中 3 次后消散 |
| 共鸣值 | 唯一分数；单关历史最高分可计入个人总分 |
| 纯净通关 | 全程未使用道具的通关 |
| 单局 / 单次会话 | 单局为进入一个关卡至结算；会话可包含多个单局 |

## 4. 功能需求编号对照

| FR-LV-08 | 中途退出恢复盘面、悲伤值、步数 | `RunState` 快照与 `SaveRepository` | T-05、AC-07 |
| FR-LV-09 | 单局≤6 分钟；40～90 步；首章 40～55 步 | 关卡配置、动画时长预算 | T-10、AC-02 |
| FR-LV-10 | 步数=模拟平均通关步数×R；每关≥1000 次模拟 | 可复现模拟输入/记录 | T-10、AC-04 |
