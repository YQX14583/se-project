# MarkHub v1.0 — 可运行作品

零依赖纯前端实现（HTML + CSS + 原生 JS + IndexedDB），离线可用，数据 100% 留在本地浏览器。

## 运行方式

```bash
cd markhub-app
python3 -m http.server 8765   # 任意静态服务器均可；直接双击 index.html 也可运行
# 浏览器打开 http://127.0.0.1:8765
```

首次打开自动创建两篇示例笔记。所有数据存于浏览器 IndexedDB（库名 `markhub-vault`），刷新/重启不丢失。

## 已实现的需求（↔《01-需求分析文档》）

| 需求 | 实现 |
|---|---|
| FR-01 创建笔记 | ＋新建笔记；标题净化非法字符 `\/:*?"<>\|` |
| FR-02 编辑器 | Ctrl/Cmd+B 加粗、+I 斜体、+K 链接；支持标题/列表/任务列表/表格/代码块/引用等语法 |
| FR-03 实时预览 | 分栏实时渲染（去抖），未闭合代码块等非法结构容错渲染；渲染器默认转义 HTML 防注入 |
| FR-04 保存 | Ctrl/Cmd+S 手动保存；停止输入 2 秒自动保存；状态栏显示保存时间 |
| FR-05 文件树 | 左栏"文件夹"分组 + 全部/回收站入口 |
| FR-06 标签 | front matter `tags:[...]` 与行内 `#tag` 双来源；点击标签过滤 |
| FR-07 收藏 | 列表项 ☆/★ 切换，收藏区独立展示 |
| FR-08 全文检索 | 多词 AND、`"精确短语"`、`tag:` / `path:` 过滤，命中片段高亮，空态有提示 |
| FR-09 双向链接 | 输入 `[[` 弹出笔记名补全；预览中点击跳转；虚链（不存在的笔记）点击即创建；底部反向链接面板含上下文摘要 |
| FR-12 导出 | 当前笔记导出 .md / .html，全部笔记合并导出 .md |
| FR-14 回收站 | 删除 → 回收站（软删除，不进搜索/链接索引）；恢复 / 彻底删除（二次确认） |
| FR-19 主题 | 亮/暗主题切换并持久化 |
| NFR-06/07 | 零网络上传：无任何外部请求、无 CDN 依赖，全部资源本地 |

测试记录：渲染器通过 14 项 Node 回归（含 XSS 转义、未闭合代码块、混合列表类型）；浏览器 GUI 冒烟覆盖创建→编辑→自动保存→双链跳转→搜索→删除→恢复→主题持久化全流程（详见作业根 README"验证"节）。

## 代码结构

```
markhub-app/
├── index.html        # 入口与三栏布局（顶栏/导航/列表/编辑区）
├── css/style.css     # 亮暗双主题，CSS 变量驱动
└── js/
    ├── markdown.js   # 自研 Markdown 渲染器（CommonMark 子集 + GFM），含链接/标签提取
    ├── store.js      # IndexedDB 数据层：增删改查、检索、反向链接索引
    └── app.js        # UI 编排：状态管理、事件绑定、自动保存、导出
```
