写作与连接

新建笔记后可编辑标题、正文与标签。停止输入 800 毫秒后自动保存，也可以按 ⌘ / Ctrl + S。

支持标题、粗体、斜体、行内代码、代码块、列表、引用和安全的 HTTP(S) 链接。原始 HTML 作为文本显示；图片、表格、任务复选框及嵌套列表不在本版语法范围内。

用 [[标题]] 连接另一篇笔记。标题必须完整匹配；同名时显示“歧义”，改成唯一标题即可。重命名不会自动修改其他笔记。

搜索为不区分大小写的连续子串匹配。多个词以完整字符串匹配，不支持逻辑运算符。标签和星标筛选可与搜索叠加。

备份包含回收站，恢复时仅添加新 ID，相同 ID 保留现有数据。服务未运行时无法打开应用；启动后不需要联网。
